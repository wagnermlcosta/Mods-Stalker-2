# My Mod Workshop - S.T.A.L.K.E.R. 2

Welcome to my personal mod workshop for **S.T.A.L.K.E.R. 2: Heart of Chornobyl**. This repository is where I develop, test, and share my game modifications.

## 🛠️ What you'll find here

This is my workspace where I create different types of game adjustments:

### Available Mods

1. **BetterBallistics_CoreStalker2-NoSway** - Complete ballistics system without weapon sway
2. **CorpseClueStash** - Adjusted spawn chance for clues on corpses
3. **DamageMultipliers** - Damage multipliers in difficulty settings
4. **Markers** - Map marker reveal distance
5. **NoSway** - Simple removal of weapon sway
6. **SwayReduced50%_HoldBreathForAll** - 50% less sway + hold breath for all weapons
7. **SwayReduced50%_VanillaHoldBreath** - 50% less sway + vanilla hold breath system
8. **VanillaSway_HoldBreathForAll** - Vanilla sway + hold breath for all weapons
9. **Vault_Sensitivity** - Vault/climbing sensitivity

## 🐍 My Python Scripts

I've developed some scripts to process game files:

- `patch_CorpseClueStashPrototypes.py` - Adjusts spawn chance on corpses
- `patch_DifficultyPrototypes.py` - Modifies damage multipliers
- `patch_MarkerPrototypes.py` - Adjusts marker distances
- `patch_ObjPrototypes.py` - Modifies object prototypes

## 🎯 About this workshop

This is not an official mod collection, but rather my personal space for experimentation and development. Here I test ideas, tweak values, and share what works for me.
